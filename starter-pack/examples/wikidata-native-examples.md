# Native Wikidata examples (not verified live)

Two items that show the shape of a well-described software item on Wikidata. Statement lists below are what the WikiProject Software property list *leads one to expect*; check on the live pages.

| Item | Q-ID | What to look at |
|---|---|---|
| YAGO | Q8045810 | developer, licence, version with qualifiers (P348 + P577), official website, programming language |
| Akregator | Q1765672 | instance of free software / feed reader, operating system, licence, source repository, software version identifier |

Pattern to copy for versions: one P348 statement per release with qualifiers P577 (publication date), P548 (version type), P4945 (download URL); preferred rank on the newest.
