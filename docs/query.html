      Ctrl+Enter runs the query. SELECT, ASK and CONSTRUCT work. A table with Point(...) values can be shown as a map, a table with image files as pictures; a comment line #defaultView:Map or #defaultView:ImageGrid opens that view first.Strg+Eingabe führt die Abfrage aus. SELECT, ASK und CONSTRUCT funktionieren. Eine Tabelle mit Point(...)-Werten lässt sich als Karte zeigen, eine mit Bilddateien als Bilder; eine Kommentarzeile #defaultView:Map oder #defaultView:ImageGrid öffnet diese Ansicht zuerst.
